# Web3Mosaic

Decentralized data storage and smart contract execution via a secure, open-source gateway framework.

With Web3Mosaic, you get a lightweight tool that stays out of your way.

**What you get**

- Decentralized data storage and smart
- contract execution via a secure,
- open-source gateway framework

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Mosaic.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Web3Mosaic is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
